# Cinder

![Cinder preview](preview.gif)

Pet name: Cinder

Description: A tiny orange pixel dog with droopy ears, a small hat, and calm coffee-in-chaos energy.

## Included Files

- `pet.json`
- `spritesheet.webp`
- `preview.gif`
- `README.md`

## Install Instructions

1. Copy the `cinder` folder into your Codex pets folder.
2. Set the active pet ID to `cinder`.

## Notes

`pet.json` and `spritesheet.webp` are the required files. `preview.gif` and `README.md` are optional helper files.
