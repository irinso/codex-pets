## Pets

### Cinder

![Cinder preview](pets/cinder/preview.gif)

A tiny orange pixel dog with droopy ears, a small hat, and calm coffee-in-chaos energy.

Install folder: `pets/cinder/`

## How To Install A Pet

1. Download this repo or a release zip.
2. Copy the pet folder you want into your Codex pets folder.
3. Set the active pet ID to match the folder name, like `cinder`.

The required files for each pet are `pet.json` and `spritesheet.webp`. `preview.gif` and `README.md` are helper files for sharing on GitHub.

## Folder Layout

```text
pets/
  cinder/
    pet.json
    spritesheet.webp
    preview.gif
    README.md
  fin/
    pet.json
    spritesheet.webp
    preview.gif
    README.md
```

## Sharing

For a clean download link, create a GitHub release and upload a zip for the pet or the whole collection. People can use the release link to download the files without cloning the repo.
